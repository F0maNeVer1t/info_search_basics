# Основы информационного поиска — задания по курсу

Данный репозиторий предназначен для выполнения и хранения заданий по курсу  
**«Основы информационного поиска»**.

Все выполненные задания распределены по отдельным веткам репозитория.

Каждое задание находится в своей ветке:

- `ex1` — задание №1  
- `ex2` — задание №2  
- `ex3` — задание №3  
- и т.д.

Таким образом, каждая ветка соответствует отдельному практическому заданию курса.
